# Glow & Grace Beauty Studio

A modern and responsive beauty studio website designed for a professional makeup and beauty business.

## Features

- Responsive design
- Home section
- About section
- Beauty services
- Gallery
- Testimonials
- Appointment booking
- Contact section
- WhatsApp integration
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Live Demo

[View Website](https://swetha1624.github.io/glow-grace-beauty-studio/)

## Project Purpose

This project was created as a professional business website concept for a beauty studio. It focuses on attractive UI design, responsive layouts, and user-friendly navigation.
